# Comandos-Docker-Linux
## 1-bake
  **Cria a partir de um arquivo**
```bash
bake
```
## 2-ps
**Listar contêiners**
```bash
ps
```
## 3-info
  **Exibir as informações de todo o sistema**
```bash
info
```
## 4-build
  **Criar uma imagem a partir de um dockerfile**
```bash
build
```
## 5-checkpoint
  **Gerencia checkpoint**
```bash
exec
```
## 6-create
  **Cria um novo contêiner**
```bash
create
```
## 7-attach
  **Anexa fluxos de entrada, saída e erro padrão locais a um contêiner em execução**
```bash
attach
```
## 8-rmi
  **Remover uma ou mais imagens**
```bash
rmi
```
## 9-save
  **Salva uma ou mais imagens em um arquivo tar(transmitido para STDOUT por padrão)**
```bash
save
```
## 10-stats
  **Exibe um fluxo ao vivo das estatisticas de uso de recursos do(s) containêr(es)**
```bash
stats
```
## 11-wait
  **Bloqear até que um ou mais contêineres parem, e em seguida, imprimir seus códigos de saída**
```bash
wait
```
## 12-unpause
  **Despausar todos os processos em um ou mais contêineres**
```bash
unpause
```
## 13-kill
  **Matar um ou mais containers em execução**
```bash
kill
```
## 14-export
  **Exportar o sistema de arquivos de um container como um arquivo tar**
```bash
export
```
## 15-update 
  **Atualiza a configuração de um ou mais contêineres**
```bash
update
```
